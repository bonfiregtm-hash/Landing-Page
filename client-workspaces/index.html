Questions,answered.

01Can I run Bonfire GTM for several clients?

Yes. Each client gets its own workspace with separate leads, plays, campaigns and pipeline.

02Who is it built for?

Agencies that win on referrals and want a second, steady source of booked calls, for themselves or their clients, without hiring SDRs.

03Are caps and suppression set per client?

Yes. Daily caps and suppression are built into every client workspace.

04Will a client's main domain ever send?

No. Bonfire GTM only sends from separate domains and inboxes, warmed for 21 days.

05Can I use it for my own agency's outbound too?

Yes. Bonfire GTM is built for agencies that want booked calls for themselves or their clients.
