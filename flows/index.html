Questions,answered.

01Do I need Zapier?

No. Triggers, research, verification, email, LinkedIn, agents and approvals all run inside one flow in Bonfire GTM. Nothing to glue together.

02Can it send LinkedIn messages?

Yes. Flows can view a LinkedIn profile, send an invite with no note, and message a connection. Each one runs after you approve it.

03Does anything send without me?

Nothing risky. Emails, LinkedIn steps and agent changes land in Needs you until you approve them. Test run is a dry run on the latest matching item, so nothing changes.

04What triggers a flow?

Three things: New signal (a funding, hiring, launch or leadership signal is found), New lead (a lead is added from an import, list builder, play or agent) and New reply (someone replies to a campaign email).

05How long does setup take?

About 15 minutes for your first flow: pick a trigger, add steps, do a test run and switch it on. New sending inboxes still warm up for 21 days before they send at full volume.
